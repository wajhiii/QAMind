# QAMind (generated Claude Code plugin)

Install from the repository's marketplace:

```
/plugin marketplace add <owner>/qamind
/plugin install qamind@qamind
```

Then run `/qamind:qa-only`. See the repository README for first-run setup and usage.

This folder is generated from `core/` and `hosts/claude/` by `npm run build`. Do not edit it by hand; CI fails if it is out of date.
