# memory-v1: a real memory store written by QAMind 0.7.5 (memory schema 1)

Two finished runs (`full` on Claude Code, `quick` on Cursor with a cost of "$0.31"), learnings, a false alarm, a risk area, the product map and the stack, exactly as the Phase 7.5 build wrote them
